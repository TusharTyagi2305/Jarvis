# JARVIS Configuration Reference

Configure settings via `.env` file or environment variables.

| Variable | Default | Description |
| --- | --- | --- |
| `API_HOST` | `127.0.0.1` | REST API host address |
| `API_PORT` | `8000` | REST API port number |
| `GEMINI_API_KEY` | `""` | Gemini API key for multimodal vision & reasoning |
| `VISION_CLICK_CONFIDENCE_THRESHOLD` | `0.85` | Vision target confidence threshold |
| `ALLOW_AUTOMATIC_MEMORY` | `false` | Enable/disable automatic memory persistence |
| `JARVIS_BACKGROUND_MODE` | `true` | System tray background mode |
